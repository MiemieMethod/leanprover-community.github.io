监管团队

监管团队负责处理 GitHub 上（在 leanprover-community 组织内）与 Zulip 上评论与消息的监管事务。在 Zulip 上，这包括创建新的私有或公开频道、整理现有频道以及将消息移动到合适的话题之下。在两个平台上，它都涉及隐藏或删除违反行为准则的评论；Zulip 上的用户可被暂停（临时停用）或封禁（永久停用）。

监管团队的成员来自 Mathlib、CSLib 以及更广泛的 Lean 社区。Mathlib 与 CSLib 领域之间存在一种非正式的区分：Mathlib 监管员不会监管 Zulip 上的 CSLib 频道或 GitHub 上的 cslib 仓库（反之亦然，CSLib 监管员也不监管 Mathlib 仓库或 Zulip 上的 mathlib 频道）。当前成员如下。
