社区团队 #

若干由社区成员组成的团队各自承担着指定的职责。

管理团队

管理团队负责监督 Lean 社区组织的各项活动，尤其是 mathlib 项目。它负责确保 mathlib 项目持续反映 Lean/mathlib 社区的普遍观点与利益。

更多信息

mathlib 维护者

mathlib 维护者有权批准对 mathlib 的更改与新增内容。该团队负责 mathlib 的整体设计，旨在维护库的连贯性，并使其各部分良好地整合在一起。

更多信息

mathlib 审阅者

mathlib 审阅团队协助 mathlib 维护者进行 mathlib 拉取请求的日常审阅。该团队由在贡献与审阅中展现出高质量的资深社区成员组成。

更多信息

持续集成

负责 Azure、bors 管理、持续集成虚拟机的 root 访问权限，以及 Lean 用户社区各项目上的 GitHub actions。

更多信息

监管团队

监管团队负责处理 GitHub 上与 Zulip 上互动的监管事务。这包括结构性监管（例如移动离题消息）以及删除违反社区规范的消息。

更多信息

行为准则团队

该团队负责处理事件报告并维护社区标准。

更多信息

网站/博客团队

网站/博客团队负责维持社区网站运行的技术基础设施。这也包括社区博客以及 mathlib 自动生成的文档。
